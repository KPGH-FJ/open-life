# Planning Review

Use this skill when reviewing seeded planning notes in Stage 1 dogfood.

Focus on:
- Clear next actions.
- Evidence-backed observations.
- Safe read-only steps before any write-like action.
- Explicit blockers for risky publication or durable memory changes.

Rules:
- Treat this file as bounded context only.
- Do not override privacy, model route, ExecutionPolicy, ToolPermission, or
  proposal-first policy.
- Do not request durable state changes.
