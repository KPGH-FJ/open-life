# OpenLife PromptStack Coverage Audit

Date: 2026-05-26

Status: PromptStack full-path audit and safety-net matrix. `prompt_stack.assembled` AgentRunEvent contract is complete for formal AgentRuntime / ExecutionFacade governed paths.

Scope: Chat, StreamChat, Scheduled, PlanMode / Plan execution, Replay, Skill runtime, Builder, Calibration, Proactive suggestions, Direct tool execution, plus additional prompt assembly findings discovered by source audit.

## Path Classification Summary

- Governed: Chat, StreamChat, Scheduled, Skill runtime, Chat proposal extraction helper, Web content summarization helper, LayeredReasoner internal prompts, Builder model-assisted extraction helpers, and PlanMode planning helper.
- Legacy compatibility: `InferenceScheduler::generate` / `generate_stream` and `llm::build_system_prompt`; Builder explicitly gated direct apply compatibility; Calibration explicitly gated direct apply compatibility.
- Not applicable: Replay, Direct tool execution, Plan action execution, Calibration report/evolution/proposal creation, Calibration prompt metadata, and Proactive suggestion generation because these paths do not assemble a model prompt or must not emit fake `prompt_stack.assembled` traces.

## AgentRunEvent PromptStack Contract

Formal Chat, StreamChat, Scheduled, and Skill governed paths now emit `prompt_stack.assembled` through the typed `build_prompt_stack_assembled_payload` builder. Each `prompt_blocks[]` item records metadata only: `id`, `version`, `purpose`, `privacy_level`, `cloud_allowed`, `token_budget`, `applies_to`, and `estimated_tokens`. The payload does not include raw prompt content, raw LifeModel, raw memory, or raw user content. Helper-only PromptStacks such as Chat proposal extraction, Web summarization, LayeredReasoner internal phases, and Builder extraction keep metadata-only helper audit traces and do not emit fake `prompt_stack.assembled` AgentRunEvents.

## Safety-Net Tests

- `execution_facade_chat_uses_prompt_registry`: Chat unknown PromptBlock fails through PromptStack instead of silently using an ad hoc prompt.
- `execution_facade_stream_chat_unknown_prompt_block_fails_closed`: StreamChat unknown PromptBlock fails closed before successful streaming.
- `scheduled_facade_prompt_stack_runtime_error_does_not_fallback`: Scheduled unknown PromptBlock is observable as a runtime failure and does not use Chat fallback.
- `governed_generation_boundary_does_not_delegate_to_legacy_generate`: `generate_governed` / `generate_stream_governed` do not delegate to legacy scheduler generation.
- `core_execution_facade_fallback_uses_governed_generation_boundary` and `prompt_stack_source_audit_classifies_governed_legacy_and_not_applicable_paths`: core/Tauri fallback source boundaries require PromptStack-governed fallback and reject direct legacy scheduler generation.
- `legacy_compatibility_summary_only_cloud_payload_filters_raw_sentinels`: SummaryOnly compatibility payloads filter raw user, raw LifeModel, raw memory, and system sentinel text before cloud routing.
- `skill_specific_prompt_stack_contains_manifest_contract_and_metadata`: Skill PromptStack includes skill id, purpose, allowed tools, input schema, and output JSON envelope requirements while trace metadata excludes raw prompt/context.
- `test_summary_only_skill_promptstack_preserves_contract_and_filters_raw_input`: SummaryOnly cloud payload preserves Skill IO contract / JSON envelope / proposal policy while removing raw skill user input and raw context sentinels.
- `test_summary_only_skill_promptstack_marker_injection_does_not_leak_raw_input`: User-controlled fake Skill block markers cannot influence SummaryOnly contract preservation or leak raw input.
- `skill_runtime_prompt_stack_failure_persists_failed_run_with_safe_payload`: Unknown PromptBlock creates an observable failed Skill run and safe `run.failed` payload.
- `proposal_extraction_prompt_stack_has_stable_contract_blocks`: Proposal extraction has stable block IDs/versions and includes supported proposal types plus JSON output contract.
- `test_model_json_parse_failure_has_explicit_heuristic_fallback_reason`: invalid model JSON enters explicit heuristic fallback with metadata-only failure reason.
- `test_unknown_proposal_prompt_block_falls_back_with_audit_metadata`: unknown Proposal PromptBlock does not silently proceed and records `prompt_stack_assembly_failed`.
- `proposal_extraction_summary_only_prompt_excludes_raw_sentinels` / `test_summary_only_audit_metadata_excludes_raw_prompt_model_output_and_sentinels`: SummaryOnly proposal extraction excludes raw user/LifeModel/model-output sentinels from prompt/audit boundaries.
- `test_local_only_unavailable_model_does_not_use_cloud`: LocalOnly local-model failure records `local_model_unavailable`, uses heuristic fallback, and does not attempt cloud.
- `web_summarization_prompt_stack_has_stable_contract_blocks`: Web summarization has stable block IDs/versions/purpose and JSON output contract.
- `web_summarization_summary_only_prompt_excludes_raw_sentinels` / `test_summary_only_web_summarization_audit_metadata_excludes_raw_content`: SummaryOnly web summarization excludes raw fetched content and raw URL sentinels from assembled prompt and audit metadata.
- `test_local_only_web_summarization_unavailable_does_not_use_cloud`: LocalOnly web summarization records `local_model_unavailable`, does not attempt cloud, and returns a non-raw fallback.
- `test_unknown_web_summarization_prompt_block_fails_closed` / `test_invalid_web_summarization_model_output_has_stable_failure_reason`: Web summarization fail-closes on unknown blocks and invalid model output without falling back to a bare prompt or raw content.
- `layered_reasoner_prompt_stack_has_stable_contract_blocks`: LayeredReasoner meaning / strategy / generation / safety / privacy blocks have stable IDs, versions, purposes, and output contracts.
- `test_unknown_layered_reasoner_prompt_block_fails_closed`: unknown internal LayeredReasoner blocks fail closed with `unknown_prompt_block` and do not continue through a legacy naked prompt.
- `layered_reasoner_summary_only_prompt_excludes_raw_sentinels` / `test_layered_reasoner_block_trace_excludes_raw_prompt_and_sentinels`: SummaryOnly internal prompts and block-trace metadata exclude raw user, raw LifeModel, goal, memory, and prompt sentinels.
- `builder_prompt_stack_has_stable_contract_blocks`: Builder model-assisted extraction helpers have stable block IDs, versions, purposes, and output contracts.
- `builder_summary_only_prompt_excludes_raw_sentinels`: Builder SummaryOnly helper assembly excludes raw user, raw LifeModel, raw memory, and raw goal/value sentinels.
- `unknown_builder_prompt_block_fails_closed`: unknown Builder PromptBlock IDs fail closed through PromptStack assembly.
- `builder_model_generation_source_uses_promptstack_governed_raw_generation`: Builder model-assisted extraction uses Builder PromptStack and `generate_raw_governed`, not legacy raw or scheduler generation.
- `test_prompt_stack_assembled_payload_contract` and `test_context_governance_applied_payload_contract`: typed payload builders record PromptBlock id/version/purpose/privacy/cloud/budget/applicability metadata while excluding raw prompt, raw LifeModel, raw memory, and raw user sentinels.
- `prompt_stack_source_audit_classifies_governed_legacy_and_not_applicable_paths`: source/document lock for governed, intentionally legacy, and not-applicable paths.

## Current Gaps

Builder model-assisted extraction is now a Builder-specific PromptStack boundary, but Builder remains outside AgentRuntime/ExecutionFacade and has no formal AgentSpec selection or PromptStack AgentRunEvent. Calibration is currently deterministic/proposal-only and not applicable for PromptStack until it becomes model-assisted. Skill runtime remains outside Chat ExecutionFacade. Proactive suggestions are suggestion-only and do not create AgentRun or PromptStack trace. Chat proposal extraction and web summarization now have dedicated PromptStack helpers and structured metadata-only audit, but still have no AgentRunEvent store integration. LayeredReasoner internal prompts are now a PromptStack-governed internal strategy boundary with metadata-only `ReasoningTrace` block traces and no fake `prompt_stack.assembled` events. Legacy scheduler generation remains a compatibility-only prompt path and is not used by formal AgentRuntime / ExecutionFacade governed calls or their runtime fallback. PromptStack assembled AgentRunEvent payload is metadata-only, includes typed PromptBlock metadata, and excludes raw prompt. Context governance event payload is metadata-only and excludes raw LifeModel.
