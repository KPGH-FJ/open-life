# OpenLife PromptStack Coverage Audit

Date: 2026-05-25

Status: PromptStack full-path audit and safety-net matrix. This is a code-fact document, not a migration plan completion claim.

Scope: Chat, StreamChat, Scheduled, PlanMode / Plan execution, Replay, Skill runtime, Builder, Calibration, Proactive suggestions, Direct tool execution, plus additional prompt assembly findings discovered by source audit.

## Safety-Net Tests

- `execution_facade_chat_uses_prompt_registry`: Chat unknown PromptBlock fails through PromptStack instead of silently using an ad hoc prompt.
- `execution_facade_stream_chat_unknown_prompt_block_fails_closed`: StreamChat unknown PromptBlock fails closed before successful streaming.
- `scheduled_facade_prompt_stack_runtime_error_does_not_fallback`: Scheduled unknown PromptBlock is observable as a runtime failure and does not use Chat fallback.
- `skill_runtime_prompt_stack_failure_persists_failed_run_with_safe_payload`: Skill unknown PromptBlock creates an observable failed Skill run and safe `run.failed` payload.
- `test_prompt_stack_assembled_payload_contract` and `test_context_governance_applied_payload_contract`: typed payload builders exclude raw prompt and raw LifeModel.
- `prompt_stack_source_audit_classifies_governed_legacy_and_not_applicable_paths`: source/document lock for governed, intentionally legacy, and not-applicable paths.

## Current Gaps

Builder prompt remains legacy/ad hoc. Calibration prompt remains legacy/ad hoc. Skill-specific facade boundary remains unbuilt. Proactive suggestions are suggestion-only and do not create AgentRun or PromptStack trace. Chat proposal extraction and web summarization helpers are additional legacy/ad hoc prompt assembly points. PromptStack assembled event payload is metadata-only and excludes raw prompt. Context governance event payload is metadata-only and excludes raw LifeModel.
