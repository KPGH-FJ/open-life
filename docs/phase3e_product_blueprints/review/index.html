07 · Approval Boundary

必须保持的状态路径

查看不改变状态；批准不等于应用；完成只能来自刷新后的读模型。

  1. 1待审核展示一句话建议、当前 → 建议、原因、影响、风险、来源
  2. 2确认决定拒绝 / 稍后 / 修改 / 批准变更
  3. 3已批准，尚未应用批准只记录决定，不显示完成
  4. 4等待应用结果由后端动作和刷新读模型证明
  5. 5已应用仅当 read model 明确返回 applied
保留未知 / 陈旧 / 缺证据时 fail-closed
保留Product / Review / Debug action 分离
禁止从页面本地推导产品 truth
禁止把 fixture 数值写成后端 ready
08 · Review Gate

本轮请审阅什么

本方案尚未进入 React。你的结论会决定下一阶段是否继续。

视觉气质是否像你希望的 OpenLife？ 桌面密度是否合适，工作区是否足够专注？ 今日、工作区、任务、审核中心的边界是否清楚？ 权限与审批是否足够安全、易懂？ 移动端导航与证据访问是否符合预期？ 可否将 Codex / Cursor 白色工作台锁定为 React 重构视觉基线？
